# 影片生成規格文件

## 影片名稱
北風與太陽 (Aesop Fable)

## 使用的語音合成技術
- **語音服務**: GPT‑SoVITS / Edge‑TTS
- **語音模型**: `zh‑TW‑HsiaoYuNeural`
- **語音參數**: Pitch `+15Hz`，速度保持預設值

## 圖片資源生成方式
- **背景與角色圖片**: 透過 Stable Diffusion + ControlNet 產生符合劇情的 PNG 素材。
- **角色 GIF 動畫**: 使用 OpenAI 的 DALL·E 產生靜態角色圖，再使用 `ffmpeg` 產生簡易搖晃、擺手、走動的 GIF 動畫。
- **素材路徑**: `public/assets/` 目錄下的 `bg_mountain.png`, `north_wind.png`, `traveler_coat.png`, `warm_sun.png` 等。

## 字幕生成與硬字幕燒錄
- **字幕生成**: `tmoroney/auto-subs` (Whisper) 自動產生 SRT 字幕，最大 16 個字每行，並自動分段顯示。
- **硬字幕燒錄**: 使用 `drawCanvasSubtitles` 把字幕渲染到影片畫面上。

## 影片輸出
- **輸出格式**: 1080p MP4、60fps
- **輸出路徑**: `C:/GitRoot/CarrotStudio/carrot-video/北風與太陽/video/北風與太陽.mp4`

## 渲染流程概述
1. 讀取 `sample_story.json`，解析每幕場景。
2. 依場景呼叫語音服務產生語音檔 (`scene_{n}.wav`)。
3. 產生/取得背景與角色圖片，合成每幕影片片段。
4. 使用 `auto_subs` 產生字幕檔 `.srt`，並用 `drawCanvasSubtitles` 燒錄硬字幕。
5. 使用 `ffmpeg` 合併所有片段，輸出最終 MP4。

---

> **注意**: 若需自訂聲音或更換圖片，只需修改 `sample_story.json` 中的 `voice`、`bgImage`、`charImage` 欄位，即可重新渲染。
